## “CN2 优化”和“三网 CN2 GIA”的区别

CN2 是中国电信的下一代承载网，下面分 GT 和 GIA 两档。GT 便宜，晚高峰容易和普通流量一起排队，回程常常绕回 163 骨干网；GIA 是优先级更高的优化线路，全程走 59.43 段的节点，延迟和丢包表现更稳。买之前要问清楚到底是不是 GIA，不能只看“CN2”几个字就付钱。

LightLayer 这条线的构成是：电信方向走 CN2，联通和移动走 CMIN2，属于国内优化线路。它比纯国际 BGP 强，但和“三网回程全走 CN2 GIA”是两种东西，后者通常在更高价位的套餐上才给。另一个容易买错的地方是，同一份 1 核 1GB 配置在 LightLayer 有优化线路、标准回程、国际线路三个入口，价格接近、路由不同。下单时一定确认购物车里选的是 Optimized 那一条，这个差价花得值不值，全看你选对了没有。
